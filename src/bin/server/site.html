Inbound

One feed businesses post offers into, and agents subscribe to.

An agent that wants something does not go looking for it. It subscribes once, is told when any offer lands, and keeps the channels its own person cares about. It ranks what it keeps against that person's situation, on its own machine, and bothers them once.

The seller never learns who was listening. The operator never learns which channels anyone came for, because everyone reads the same stream.

    The middle column is where the single feed earns its keep. A subscription to a named channel is itself a disclosure: an agent asking only for cars/ev/us would be telling the operator its person is shopping for a car, which is worth something whether or not a name comes with it. Taking everything costs bandwidth and reveals nothing.

    The operator's advantage over a search engine is not that it knows more. It knows strictly less. It is just pointed the other way.

    Connect something to it

    Nothing about the agents in this demo is special. The feed is plain HTTP.

    curl -N  /feed/stream            · be told
curl -N  /feed/stream?since=0    · backlog, then be told
curl -s  /feed/offers?since=0    · catch up
curl -s  /registry               · what exists

    There is an MCP endpoint at /mcp too, so a connector-capable agent attaches by URL instead of someone writing a client. The operator carries exactly one event type, inbound.offer, with the channel as a field on the payload and no subscription arguments — a filter in the arguments would be evaluated by the operator, which is how it would learn what an agent is looking for.

    Every offer arrives as readable JSON and as bytes, the canonical encoding the seller signed. An agent checks that signature itself, so an operator that quietly rewrites a rate has its offers dropped by the agents reading them. This page does not check it — it renders what the operator served, and is the weaker reader for it.

    What this leaves out

    • Nothing is ever bought. Offers are received and ranked. Acceptance, settlement and billing are out of scope here, so no seller is ever charged.
    • The log is not authenticated. An agent can tell that an offer was not altered. It cannot tell that one was withheld — and withholding the best offer is an operator's most profitable move.
    • An offer cannot be withdrawn. The log only grows, so an offer stands until it expires. A seller-signed withdrawal is the missing piece.
    • Conditions are checked, never proved. The agent decides locally whether better terms apply. Proving that to a seller without giving up the reason is the extension.
    • Push only reaches a connected agent. The cursor exists because an agent that was switched off missed everything.
